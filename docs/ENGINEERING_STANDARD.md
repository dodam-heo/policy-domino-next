# 정책도미노 NEXT — 개발·품질·제출 기준

## 제품 목적

공식 정책·법령·행정규칙·자치법규 등의 개정이 **어느 공공기관의 어떤 업무·사업 검토사항으로 이어지는가**를 원천 증거와 함께 추적한다.

공공기관의 범위는 중앙부처·지방자치단체·교육청·공공기관이며 민간조직은 분석 대상에 넣지 않는다. 직제 변경·복지급여는 범용 변경의 **사례일 뿐** 고정 분기, 정답 목록, 하드코딩 대상이 아니다.

## 모듈별 단일 책임

**공공기관 수집 확장:** `gov24.py`는 중앙부처·지자체·교육청·공공기관의 공식 공공서비스 정보를 인증된 원천에서 증분 수집한다. `gov24_contract.py`는 서비스명·기관명·근거법령·변경 조문 간 근거 일치와 탐색 후보/확정 조치 구분을 검증한다. API 인증이 없는 경우에도 정상 실행하며, 미설정 상태를 기록하고 임의의 기관·사업은 생성하지 않는다.


| 모듈 | 역할 |
|---|---|
| `api.py` | 공식 목록 검색, 공포번호·일자·법령 종류·버전 ID 수집 |

| `discovery.py` | 공식 관련 규정 탐색 및 정확한 인용 확인 |

| **`events.py`** | 원천 법령별 독립 변경 사건 생성, 근거별 기관·사업 업무 검토사항 구성 |

## 독립적인 주장·근거 단계

1. **수집:** 공식 문서의 ID·공포일·법령 종류·이력
2. **변경:** 비교 가능한 실제 종전·현행 조문의 원문·해시
3. **사건:** 원천 변경 법령 한 건에 대응하는 독립 사용자용 변경 사건
4. **기관 직접 규율:** 해당 기관의 조직·직제 규정 자체가 변경된 사실
5. **조문 명시 수행주체:** 실제 변경 조문에서 역할을 특정할 수 있는 경우
6. **공식 사업 연결:** 공식 사업 원문에 정확한 법령·조문 인용 또는 검증된 중간 경로가 있는 경우
7. **검토사항:** 근거가 확인된 변경 내용과 기관의 담당 운영기준을 대조할 항목
8. **AI 초안:** 위의 검증된 ID·인용 자료에 근거한 추가 분석
9. **실제 반영·조치:** 별도 공식 이행 증거가 있어야 알 수 있으며 현재 구현하지 않음

4~6번은 각각 **다른 근거 수준**이다. 단순 부처명 노출·기관명 등장·주제 유사도로 사업을 확정하지 않는다. 반대로 실제 변경된 직접 규율 대상 업무를 공개 사업 인용이 없다는 이유만으로 화면에서 지우지 않는다.

## 필수 품질 게이트

- **법령별 격리:** 공포번호·일자·법령 종류가 같더라도 서로 다른 법령은 별도 사건으로 표시. 등대유산 관련 조문이 다른 법령의 핵심으로 올라가거나 예금보험공사 업무가 무관한 법령에 붙는 교차 병합을 차단
- **조문 의미 판정:** 인용번호 변경과 실제 집행기준 변경을 구별하고, 서로 다른 기관·제도의 문구가 나왔다고 동일 주체의 명칭 변경으로 가정하지 않음
- **원문 완전성:** `③` 같이 항 번호만 확보된 종전/현행 본문은 신구 변경 확정의 증거가 아니며 원문 재확인 대상으로 구분
- **대표 변경 우선순위:** 공공기관 업무·공식 사업과 연결된 실질 변경을 우선 표시하고 단순 인용 수정·원문 불완전 항목을 후순위 배치

- **완전성:** 변경 조문이 빠지거나 다른 사건에 중복 편입되면 계약 실패
- **기관 근거:** 기관별 검토사항의 기관·조문·원문·사업 연결 근거가 확인되지 않으면 실패
- **조치 상태:** 직접 검토 대상은 제공하되, 조치 완료/미조치 여부는 임의 추정 금지
- **AI 검증:** 기관 ID·업무 검토 ID·사업 ID와 직접 원문 인용이 입력 근거에 없으면 실패
- **범용성:** 금액·자격·절차·기한·조직·서식·허가의 별도 합성 사례로 회귀검증
- **화면:** 기본 단위는 정책 사건, AI 사용 여부보다 기관별 업무 변경이 앞. 정책 상세 내 기관명 필터는 해당 사건의 실제 분석 기관 목록으로 자동 구성하며 PC 왼쪽 검색/전체 복귀, 모바일 기관 선택, 다른 사건으로 이동 시 초기화까지 검증. 모바일 목록→상세→뒤로·깊은 링크 정상
- **수집 진도:** 색인 건수와 분석 완료 건수는 다름. 미분석·재확인·단계적 재확인 유예·미완료 수집 구간을 분리 표시하고 개별 출처의 수집 실패가 타 출처의 역사적 이력 수집을 가로막지 않아야 함
- **대기열:** 최신 문서만 반복 처리하지 않고 장기 미처리·최근 미처리·재확인 대상 모두 일정한 처리 기회를 확보하며 시간 예산을 넘기기 전에 상태를 저장
- **원천 상태 저장:** 단일 `data/state.json`의 GitHub 100MB 한도를 회피하기 위해 압축·결정론적 버킷 단위로 기록. 저장 상태는 병합 시 원본과 일치해야 하고, 누락·손상 버킷은 조용히 무시하지 않음. Git commit은 실제 수정된 참조 버킷 및 새로운 불변 콘텐츠 팩만 포함한다. 웹의 `catalog.json`·`sources.json`·정책별 상세는 공식 근거 계약 통과 후 재생성
- **주기 분리:** 정기 실행 시 공식자료 수집+비교 작업과 기존 문서 집중 비교 작업을 교차 운영. 공식 색인 단계는 150초 상한으로 비교에 시간을 남기고 `--analysis-only`는 기존 원천을 유지한 채 분석만 실행하며, 배포는 근거 검증 후 한 번 수행
- **필터:** 첫 목록에서는 전체·신규·개정·폐지·영향도 큼의 5개 버튼만 사용하고, 특정 정책 분야에 고정 메뉴를 배정하지 않음. '영향도 큼'은 검증된 별도 공공기관 2곳 이상이라는 연결 범위 기준이며 사회경제적 파급력 평가로 오인되지 않도록 명시
- **배포:** Python/JavaScript 테스트와 공식 근거 검사 후 GitHub Pages에 **실행당 한 번만** 배포. 코드 push는 신속한 사이트 갱신, 정기·수동 실행은 수집·Gemini 결과 검증·저장 후 배포. Pages 실패 때문에 원천 수집·AI를 건너뛰지 않고, 배포 제한은 작업 25분/Pages 동기화 20분
- **Actions 버전:** Node24 기반 checkout@v5·setup-python@v6·configure-pages@v6·deploy-pages@v5, 공식 upload-pages-artifact@v4 사용 (종속 액션의 경고는 별도)
- **코드:** 단일 명령 진입점 및 하나의 워크플로; 이전 저장소나 legacy 결과 의존 금지

## 구현 완료와 남은 개발 구분

### 반영된 소프트웨어

- 원천 문서 검증 후 사건을 독립적으로 구성하는 `events.build_events`
- 직접 규율기관·명시 수행주체·공식 사업 인용의 서로 다른 출처 기반 업무 검토사항
- 증거 검증된 AI 보조 결과의 조문/기관/사업 연결
- 실제 검증 사건에 대한 목록·상세·기관별 묶음·신구 대조 접기
- 법령 간 사건 혼합·기관 증거 위조를 차단하는 회귀테스트와 계약검증

### 미완성·제출 전 별도 실측 필요

- 고시의 첨부표, 각 부처·지자체·교육청·공공기관 사업 운영기준의 전국 수집
- 변경 조문의 직접 언급·직접 인용을 넘어서는 간접 영향 발견율 검증
- 공공기관의 후속 실행 이력 자동 확인
- 장기 원천 이력의 독립 공식 대조, 누락된 기관·사업 연결의 범위 검증 및 전국 행정서비스 자료 확장
- 실제 서로 다른 분야의 정책 사건을 대상으로 하는 정밀도·재현율·누락률 측정

**화면에 분석 결과를 표시했다는 사실만으로 전국 공공서비스 영향분석을 완성했다고 주장하지 않는다.**

- **공식 고시 등:** 행정규칙 종류 knd=1~6의 현행·연혁별 원천 커서를 독립 관리하며, 과거 조회는 28일(법령·자치법규 14일) 구간으로 앞당겨 기록. 구간이 실제로 완결됐을 때만 커서를 전진시키며 API 종류코드·상세 원문 증거가 있을 때만 미분류 상태를 정정
- **공공기관 업무:** 실제 정부24 서비스의 운영 필드와 공포 조문을 대조하는 검토 항목만 공개, 실증되지 않은 완료·의무 주장을 금지
- **핵심 화면:** 짧은 요약 우선, 신구는 해당 문서에서 실제로 바뀐 구절 위치의 앞뒤 문맥·변경부분 강조를 펼쳐보기로 표시. 전체 원문·공식 서비스 기준 증거도 별도 접기로 제공

- **기관별 조회:** 공공기관 직제 등에서 원천이 뒷받침하는 직접 대상 기관을 추출하고, 정부24 기준 검토 후보를 동일 기관 필터에서 별도의 근거 등급으로 함께 탐색. 서비스/기관명을 하드코딩하지 않음
- **공식자료 검색:** 변경 사건 밖의 공식 색인 문서를 검색 시 별도 표시하여 누락된 수집과 신구 미분석을 구별함. 미분석 자료를 변경 확정으로 간주하지 않음
